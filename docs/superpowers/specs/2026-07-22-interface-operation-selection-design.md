# 接口选择工作区调整设计

日期：2026-07-22

## 背景

当前接口用例流程在 OpenAPI 导入后，中央工作区仍以提示状态为主，接口列表则挤在 220px 左侧上下文面板中。接口名称和路径难以扫描，批量选择空间不足。同时，默认面包屑文案与当前产品定位不一致，生成粒度分段控件也偏大。

本次调整沿用现有 Studio Canvas 浅色柔和主题和深蓝主操作，不改变 OpenAPI 解析、筛选、生成、AI 评审、保存或交付业务逻辑。

## 已确认方案

采用视觉对比方案 A：紧凑中央表格。

- 默认面包屑从 `默认项目 / 用例生成` 调整为 `智能用例设计 / 用例生成`。
- 左侧上下文面板只保留筛选和生成配置。
- OpenAPI 导入成功后，中央工作区立即显示接口选择表格。
- 生成粒度使用约 32px 高、三项等宽的紧凑分段控件。

## 页面布局

### 左侧上下文面板

左侧保留：

- 模块筛选
- 路径关键词
- 摘要关键词
- 请求方法
- 用例模板
- 生成粒度

左侧不再显示接口列表、已选数量、全选或清空操作。上下文面板在桌面保持现有 220px 宽度；紧凑桌面继续使用现有 `ResponsiveDrawer`。

### 中央接口表格

导入成功后，中央区域显示一层无嵌套卡片的接口表格表面。顶部工具栏包含：

- `接口列表`
- 当前筛选结果数量
- 全局已选数量
- `全选当前结果`
- `清空选择`

表格列为：

1. 选择框
2. 请求方法
3. 模块
4. 接口名称
5. 请求路径

请求方法使用文本标签，不仅依赖颜色。接口名称和路径允许省略显示，并提供完整 Tooltip。表头固定，表体独立滚动；窄屏时表格横向滚动，不压缩基础表格字号。

## 阶段行为

### 未导入

中央区域保持现有 OpenAPI 导入空状态，导入按钮和阶段主操作均可触发文件选择。

### 已导入，仍在导入阶段

导入完成后不再显示“已导入”提示页，立即显示中央接口表格。左侧筛选变化实时更新中央表格。

### 配置生成阶段

进入 `配置生成` 后，在尚未生成用例时继续显示中央接口表格。用户可以继续筛选和调整选择范围，并通过阶段主操作生成用例。

### 已生成

生成用例成功后，中央区域切换为现有 `InterfaceCaseTable`。AI 评审和保存/交付阶段行为保持不变。

## 选择语义

- 单行勾选更新 `selectedOperationIds`。
- `全选当前结果` 只添加当前筛选结果，不清除其他筛选条件下已经选择的接口。
- `清空选择` 清除全部已选接口。
- 筛选变化不得静默清除已选接口。
- 工具栏的“已选数量”显示全局选择数量，不只统计当前可见行。
- 切换导入项目时沿用当前项目切换的既有重置规则。

## 组件边界

### `InterfaceCaseContextPane`

职责收窄为筛选与生成配置。移除以下接口：

- `operations`
- `selectedOperationIds`
- `toggleOperation`
- `selectFiltered`
- `clearSelected`

仍保留筛选字段、模板和生成粒度的受控属性及事件。

### `InterfaceOperationTable`

新增展示组件，接收：

- `operations: ParsedOperation[]`
- `selectedIds: string[]`
- `loading?: boolean`

发出：

- `toggleOperation: [operation: ParsedOperation, checked: boolean]`
- `selectFiltered: []`
- `clearSelected: []`

组件使用受控选择状态，只负责表格展示和单行选择事件，不复制筛选逻辑，也不直接修改父级状态。这样筛选结果变化时，隐藏行的全局选择不会被表格的可见行集合覆盖。

### `App.vue`

继续持有：

- `filteredOperations`
- `selectedOperationIds`
- `toggleOperation`
- `selectFilteredOperations`
- `clearSelectedOperations`

新增中央接口表格的阶段渲染判断，不改变生成、评审和交付业务函数。

## 文案与尺寸

- 当全局项目名仍为默认值且位于接口用例工作区时，顶栏项目标签显示 `智能用例设计`。
- 页面区段标签继续显示 `用例生成`。
- 生成粒度控件宽度填满左侧字段容器，高度约 32px。
- 三个分段项等宽，字号使用现有 `--font-size-xs` 或等价 12px token。
- 控件圆角使用现有 `--radius-control`，选中项使用 `--brand-primary` 相关语义 token。

## 空状态与错误处理

- OpenAPI 尚未导入：显示导入空状态。
- 已导入但筛选结果为空：显示统一 `WorkflowStateView` 筛选空状态，并提供清除筛选动作。
- OpenAPI 解析失败：沿用现有导入错误提示，不由接口表格吞掉异常。
- 表格加载时保留稳定高度，避免工具栏和阶段头跳动。

## 响应式与可访问性

- 桌面：左侧上下文 + 中央接口表格；AI 评审阶段继续使用右侧检查器。
- 1024px：筛选与生成配置进入左侧抽屉，中央接口表格保持可见。
- 600px 以下：沿用现有两行 WorkflowHeader，表格保持横向滚动。
- 表格选择框、全选和清空按钮均可键盘操作。
- 请求方法、选择统计和空状态均使用可读文本，不使用纯颜色表达。
- 抽屉关闭后继续恢复到触发按钮焦点。

## 验收与测试

组件测试覆盖：

- 左侧面板不再渲染接口列表。
- 生成粒度控件具有紧凑、等宽布局契约。
- 中央表格渲染列、行和选择统计。
- 单选、全选当前结果、清空选择事件。
- 父级选择在筛选变化后保持。

结构和领域测试覆盖：

- 默认面包屑为 `智能用例设计 / 用例生成`。
- 导入后立即渲染 `InterfaceOperationTable`。
- 配置生成阶段在生成前继续渲染接口表格。
- 生成后切换到 `InterfaceCaseTable`。

Playwright 覆盖：

- 导入 OpenAPI 后中央接口表格立即出现。
- 筛选、选择和生成流程可用。
- 1280px/1440px 桌面截图。
- 1024px 抽屉和表格横向滚动。
- 键盘、焦点恢复和 axe 检查。

## 不在本次范围

- 不增加接口详情编辑器。
- 不增加分页、服务端筛选或虚拟滚动。
- 不改变生成用例字段、AI 评审规则或保存/交付接口。
- 不改变非接口用例工作区的项目标签逻辑。
